# Creadores De Fantasias

Hola. Crea el codigo en html para una app de control de mercadería.  Que permita ingresar registro de mercadería con codigo, nombre y cantidad, y se pueda agregar en cualquier momento el stock nuevo. También una parte donde se pueda cargar la mercadería vendida por dia, cuanto se vendió cada producto y haga el descuento de el stock que teníamos. Al final del dia que informe cantidad de mercadería vendida de cada producto, productos en stock y cuanto dinero se recaudo ese dia. Que lo haga en una planilla tipo Excel. Cuando entras que muestre dos carpetas, una que diga stock de productos y ahí guarde la información del stock y se pueda agregar mas productos y otra carpeta que diga productos vendidos ahi se pueda agregar las ventas diarias. Que vaya sumando todo lo del dia y lo informe, pero también que lo caya acumulado en una planilla donde se vea toda la información diaria y el total hasta ese momento. Arriva puede decir producto, codigo, cantidad, precio para el conteo del dia, y fecha, cantidad de productos, precios y total recaudado para lo que seria el conteo semanal.
